# Huntboard logo

A magnifying glass (the search) framing three board columns whose cards rise like a chart (your applications moving
forward).

| File | Use |
|---|---|
| `huntboard-mark.svg` | the symbol alone, light backgrounds |
| `huntboard-badge.svg` | app icon / favicon (rounded tile) |
| `huntboard-logo.svg` | symbol + name, light backgrounds |
| `huntboard-logo-dark.svg` | symbol + name, dark backgrounds |
| `social-preview.svg` | GitHub social preview (1280 × 640) |
| `png/` | PNG exports: `node tools/export-logo.js` |

## Colours

| Token | Light | Dark |
|---|---|---|
| Brand (teal) | `#0f766e` | `#2dd4bf` |
| Brand light | `#14b8a6` / `#5eead4` | `#5eead4` |
| Accent (amber) | `#f59e0b` | `#fbbf24` |
| Lens fill | `#ecfdf5` | `#123532` |
| Ink | `#17201e` | `#e7efec` |

The name is set in Segoe UI / Inter Bold; "board" is in the brand colour.
