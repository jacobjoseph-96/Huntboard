# Roadmap

## 0.1 (this version)

| Area | What | State |
|---|---|---|
| Foundation | One source of AI instructions for every AI tool (`agent/` → `npm run sync`), install and start scripts | done |
| App | Tickets instead of a spreadsheet: board, ticket view, profile, documents, settings, setup wizard, chat, AI activity | done |
| AI runner | The AI runs in the background (buttons + chat); its questions are dialogs in the app | done: Claude Code tested; Antigravity needs "Let the AI work without asking" for some steps; others experimental |
| Board choice | Registry of 44 boards in 20+ countries, ranking by country, field and job type, search plan per search | done |
| Search | API boards read directly, browser playbooks, duplicates across boards, filters with reasons, fit score | done |
| Documents | CV in the job country's language and style, tailoring, cover letters, attachments PDF, e-mail drafts, fact check | done |
| Applying | off / fill forms / apply after one OK / fully automatic, decision log, "Needs you" list | done |
| Interviews | Preparation per interview step, debrief, thank-you draft, follow-up reminders | done |

## Next

- Run a search on a schedule (e.g. every morning) for fully automatic mode.
- Learn from outcomes: which boards and kinds of jobs lead to interviews, and weigh the fit score with it.
- Read replies from the mailbox and suggest status changes (rejection, interview invitation…).
- Verify the experimental AI tools on real machines, and more country playbooks.
- Optional desktop packaging.
